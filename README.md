## 📌 Coursework Overview

This repository contains homework assignments, mathematical derivations, and code from the **AIN313 Machine Learning Laboratory** course at **Hacettepe University (Department of Artificial Intelligence Engineering)**:

### 1. Assignment 1: KNN & Medical X-Ray Disease Detection
- **Theoretical Foundations:** Mathematical derivation of distance metrics (Euclidean, Manhattan, Minkowski) and boundary sensitivity to $k$.
- **Practical Application:** Automated disease identification on chest X-Ray image features using $k$-Nearest Neighbors classification.

### 2. Assignment 2: Maximum Likelihood Estimation (MLE) & Probabilistic Models
- **Theoretical Derivations:** Analytical parameter estimation via Maximum Likelihood Estimation (MLE) and Maximum A Posteriori (MAP).
- **Classification & Regression:** Gaussian Naive Bayes and Logistic Regression decision boundaries.

### 3. Assignment 3: Margin Classifiers & Ensemble Methods
- **Support Vector Machines (SVM):** Primal and dual formulations, slack variables for soft-margin optimization, and kernel tricks (Linear, Polynomial, RBF).
- **Decision Trees & Ensembles:** Impurity metrics (Gini impurity, Information Gain / Entropy), Random Forests, and bagging vs. boosting comparisons.
